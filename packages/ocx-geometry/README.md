# ocx-geometry

Geometry evaluation kernel for the OCX IR: curve sampling, parametric
surface evaluation, length and area measurement, contour-closure and
junction-gap checks, 2-D section outlines, 2-D polygon topology and CutBy
hole placement. Pure numpy/shapely computation — no tessellation or
display stack. Used by the `ocx-rules` geometry checks.

Part of the ocx-platform workspace. See the repository root README.
