# ocx-model-validator

Validate OCX `.3docx` ship model files: schema validation, model reports
(frame table, compartments, panels, plates, stiffeners, brackets, pillars,
BOM) and the `validator` / `ocx-validate` CLI. The `ocx-mcp` MCP server
lives in [OCXStandard/ocx-mcp](https://github.com/OCXStandard/ocx-mcp).

Depends on `ocx-model-core` (parsing + IR) and `ocx-geometry` (geometry
checks). Part of the ocx-platform workspace. See the repository root
README.
